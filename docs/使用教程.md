# 知识复习工作台 · 使用教程

适用版本：3.0.0；更新：2026-10-02。快速入口见[使用说明](../使用说明.md)。

## 1. 启动与首次使用

Windows 双击 `启动.cmd`；Linux/macOS 安装 Node 18+ 后执行 `bash 启动.sh`。主入口为 index.html，旧总览 HTML 是生成的兼容入口。浏览器数据按来源隔离，换端口或浏览器不会自动读到原记录。

选择知识模块或专题，搜索题干/关键词；展开参考答案学习，也可手动标记等级。模块为知识类型，专题为具体课程或题库。内置题库目前仍是原来的 6 个专题、296 题；其他类型通过自定义题库补充。

## 2. 创建和管理模块

“全部模块 / 管理”显示全部模块，可新建、自命名并设置默认、语言、概念、实践四种复习策略。重命名不改 ID，因此不改变对应记录。最近模块按使用时间排列，最多五个；“全部知识”为总览入口，不占五个位置。

## 3. 导入题库

1. 点击“添加知识”，选择“题库文件”或“粘贴题库”。两种方式都使用相同 JSON 格式，模板为 `data/import-example.json`。
2. 核对所属模块，查看新增、更新、移除预览及前后内容。
3. 默认合并：同 ID 更新，未出现在文件中的已有题保留。选择替换时，移除导入所涉及专题中未出现的旧题，其他专题保留。
4. 内容变化默认重置对应进度；仅勘误且希望保留时勾选保留进度。确认后保存并刷新。

题库 JSON 必须含 version:1、categories、subjects。题干和答案必填；最多 100 个模块/专题、2000 道自定义题。模块/专题名最多 60 字符，题干和一句话结论最多 2000，答案/解析最多 20000。超限拒绝导入，不截断。不要为另一道题复用旧 ID。

选择题 type 为“选择题”，options 为 2–8 个选项，answer 为对应字母 A–H；填空题 type 为“填空题”，多个正确答案用 `|` 分隔；简答题可省略 type 或填“简答题”。可附 explanation 和 source。详见[模型说明](开发与架构.md)。

## 4. 维护自定义题库

点击“题库管理”，编辑题干、答案、题型、选项和解析，添加/删除题目，修改专题名或移动所属模块。内置题库不能在此编辑；开发者应修改 data/subjects 后构建。

删除最后一题会移除空专题。“撤销”恢复上一次题库内容，不能代替完整学习记录恢复；完整备份用于同时恢复题库、进度和配置。“导出题库”仅导出自定义题库。

## 5. 复习与判分

等级为未记忆、忘记了、模糊、熟练、完全掌握。连续两次熟练或掌握才毕业，模糊或忘记会重置连续次数；到期题目进入复习队列。不同模块策略采用不同间隔，默认策略保留原规则。

选择题选中答案后提交；填空题按文字匹配，忽略首尾空白与英文大小写，将连续空白合并为一个空格，并规范化全角字符，不做语义同义词判断。正确记熟练，错误记忘记了。查看参考答案后点击“已回顾答案，重新练习”。

简答题可手动标记或使用 AI 自测/深测。AI 以标准答案评估覆盖率：小于 30 为忘记了，30–不足 60 为模糊，60–不足 85 为熟练，85 以上为掌握；准确率低于 40 时最高为模糊。无服务或密钥时 AI 入口禁用，本地学习仍可用。

## 6. 资料提取

1. 在“添加知识 → 资料提取”选择知识模块，导入或拖入 PDF、DOCX、JPG/JPEG、PNG、GIF；单文件最多 50 MB。旧 DOC 请先另存为 DOCX。
2. 文件在浏览器解析。PDF 数字页取字，文本不足 50 字符的页触发 OCR；每文件最多 OCR 30 页。首次加载解析库和 OCR 资源需联网。
3. 提取文本分块，每块最多约 2000 字符；生成时按最多 10 块或 24000 字符一批处理全部已有文本块。每批失败自动重试一次，仍失败可手动重试，成功结果保留。
4. 查看覆盖数、失败批次、来源原文，修改题目并标为“已确认”。模型“自评”不是客观正确率，OCR 与生成内容需人工核对。
5. 已确认题目可直接加入题库，经统一预览后保存；也可导出复习题库文件。通用 JSON/CSV/Excel 导出用于提取结果，复习题库导出用于学习导入。

原始文件、文本块和未导入结果不参与云同步或完整备份。AI 生成会把相关提取文本发送到配置的 AI 服务。文本块覆盖完整不等于 OCR 全文无误或模型没有漏题。

## 7. 备份与手动迁移

| 操作 | 包含数据 | 适合场景 |
|---|---|---|
| 导出/导入进度 | 学习记录 | 两端题目 ID 相同，仅合并记录 |
| 导出/导入题库 | 自定义题目与专题 | 分发题库，不含复习记录 |
| 完整备份/恢复 | 自定义题库、学习记录、模块配置 | 换设备、换网址、批量修改前备份 |

“备份与恢复”中导出 JSON；目标设备选择文件或粘贴完整 JSON，预览数量后选择恢复方式。合并时冲突字段采用备份值，进度按事件时间合并；完整替换作用于当前账号或访客的数据范围。可撤销上次恢复。备份最大 8 MB，浏览器存储容量可能更小。

不同网址间迁移推荐完整备份；不要把完整备份作为题库 JSON 或进度 JSON 导入。已有账号数据恢复后继续遵循云同步事件合并规则，完整替换不是清除所有远端历史的命令。

## 8. PWA 与手机电脑同步

先按[免费托管与云同步](免费托管与云同步.md)配置并部署。两端打开同一个 HTTPS 网址，登录同一账号。访客数据不会自动上传，需要明确迁移或恢复备份。

联网后修改约 1.5 秒触发同步，前台约每 60 秒检查，也可点“立即同步”。离线先保存在本机；关闭应用后不保证后台同步。冲突需逐项选择。安全时应用远端内容无需整页刷新；正在编辑或自测时暂缓，关闭后用更新内容入口应用。

手机可安装/添加到主屏幕，通过“目录与学习统计”打开抽屉。PWA“更新应用版本”更新资源缓存，与云端内容更新不同。退出账号不等于清除本机缓存；共享设备需注意这一点。

## 9. 常见问题

- 记录不见：先检查浏览器、主机名、端口、账号是否与之前一致，再考虑恢复；不要先清空存储。
- AI 不可用：检查本地服务、API Key 和 `/api/health`；静态部署无 Node AI 后端。
- 更新后仍旧界面：有更新提示时点“更新应用版本”；必要时先备份再排查缓存。
- 手机打不开本地服务：默认仅本机监听，局域网需显式设置 REVIEW_HOST，见[部署说明](部署说明.md)。局域网访问不会自动共享浏览器记录。
- 流程图/OCR/Excel 不可用：首次需联网加载第三方依赖；Excel 可回退 CSV，离线流程图显示源码。

当前验证和未验证范围见[功能完善验收](功能完善验收.md)。
