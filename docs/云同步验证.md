新增测试实际运行同步控制器，Supabase 客户端使用模拟数据库替代，不发送真实外部请求。覆盖：

- 题目不同字段与新增空模块的三方合并。
- 同一字段冲突，以及删除与编辑的冲突。
- 账号新记录保留超过 60 条完整历史、按事件 ID 去重及合并收敛。
- 相同快照中不安全对象键的拒绝。
- 云端版本竞争后的重新拉取、合并及写入。
- 网络上传过程中本机新增修改的保留。
- 离线和请求失败保留本机内容。
- 控制器等待用户选择冲突内容。
- 访客数据不自动上传、主动迁移、切换账号时禁止旧页面保存。
- 静态产物隔离，以及构建拒绝 service_role 密钥。
