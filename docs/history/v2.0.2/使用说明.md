## 3. 安装步骤

### 3.1 Windows（3 步，约 1 分钟）

1. **解压**：右键 zip →「全部解压」到任意位置，例如 `D:\Tools\嵌入式八股复习系统_v2.0.2\`。
   - 用「提取到当前文件夹」会导致文件直接散落，务必选「解压到 嵌入式八股复习系统_v2.0.2\」。
2. **（可选）配置 API Key**：把 `deepseek.key.example` 复制一份，重命名为 `deepseek.key`，用记事本打开，把第一行的占位内容换成你自己的 Key，保存。
   - 第一行请只保留 Key 本身；后面 `#` 开头的注释行会被自动跳过，不影响读取。
   - 没有 Key 也能用：手动标记等级、复习模式、搜索等功能不受影响。
3. **完成**。无需安装 Node、无需 npm install、无需配置环境变量。

### 3.2 Linux / macOS

```bash
# 1. 解压
unzip 嵌入式八股复习系统_v2.0.2_win64.zip -d ~/eb-review
cd ~/eb-review/嵌入式八股复习系统_v2.0.2

# 2. 确认 Node 18+
node -v        # 低于 v18 请先升级（macOS: brew install node）

# 3. 配置 Key（可选）
cp deepseek.key.example deepseek.key
# 编辑 deepseek.key 第一行填入真实 Key，或：
export DEEPSEEK_API_KEY="sk-你的key"

# 4. 赋予启动脚本执行权限
chmod +x 启动.sh
```

## 4. 启动方法

### 4.1 Windows：双击 `启动.cmd`

双击后启动窗口会自动完成：选择运行时 → 检测端口 → 弹出浏览器 → 前台运行服务。
看到下面这样即成功：

```
===============================================
  Embedded Review - AI Grading Server
===============================================
[INFO] Using bundled Node runtime: runtime\node.exe
[INFO] Server will listen on port 8000
[INFO] Opening browser: http://localhost:8000/review
===============================================
  嵌入式校招八股 · AI 判分服务已启动
===============================================
  快捷入口   http://localhost:8000/review
  API Key    已就绪（sk-1a2****）
===============================================
```

**停止服务**：在启动窗口按 `Ctrl+C`，或直接关掉窗口。

### 4.2 命令行启动（可指定端口）

```bat
启动.cmd            :: 默认从 8000 开始，被占自动顺延（最多到 8015）
启动.cmd 9000       :: 指定从 9000 开始
```

Linux / macOS：

```bash
./启动.sh           :: 默认 8000，被占由 server.js 自动顺延（最多 10 个）
./启动.sh 9000
```

### 4.3 不用启动脚本，直接跑 Node

```bash
# Windows（用包内运行时）
runtime\node.exe server.js 8000

# 有系统 Node 的任意平台
node server.js 8000
```

### 4.4 手机 / 平板访问（同一 WiFi）

1. 电脑上启动服务，记下窗口里 `局域网 http://<你的IP>:端口/` 那一行。
2. 手机浏览器直接输入 `http://<电脑IP>:8000/review`（例：`http://192.168.1.5:8000/review`）。
3. 打不开时是 Windows 防火墙拦截：首次启动时弹窗选「专用网络允许访问」，或手动放行 `node.exe` 的专用网络入站。

### 4.5 不启动服务时（退化模式）

直接双击 `嵌入式校招八股_总览.html` 或任一 `*_八股.html`：题目浏览、搜索、展开/折叠全部可用，手动标记等级也可用（数据存浏览器 localStorage），仅 AI 判分不可用（页面会提示「判分服务未连接」）。
「导入提取」工作台此时**本地解析仍可用**（PDF 取字 / docx / OCR / 导出，需联网加载 CDN 库），但「生成知识点 / 生成题库」两步需要服务端 AI 代理，会被禁用并提示。

## 5. 常见问题及解决方案

### Q1. 双击 启动.cmd 闪退 / 提示找不到 node
- 图标仅是一瞬间：看启动窗口内的报错文本（日志直接打在窗口里，不落盘）。
- 提示 `Node.js not found`：说明 `runtime\node.exe` 没解压出来（zip 未完整解压），重新解压整个 zip；或安装 Node 18+ 后重试。

### Q2. 提示端口被占用 / 浏览器打开是空白页
- 启动脚本已做**端口预检 + 自动顺延**：8000 被占会自动用 8001…8015，浏览器打开的就是真实端口。
- 若浏览器开早了没连上：看启动窗口里的实际端口，手动访问 `http://localhost:<那个端口>/review`。
- 想彻底避免冲突：`启动.cmd 9000` 指定一个没人用的端口。

### Q3. 页面提示「判分服务未连接」（红色）
按顺序检查：
1. 是否通过 `启动.cmd`/`node server.js` 打开的页面？`file://` 双击打开一定不可用。
2. 地址栏端口是否和服务窗口端口一致（服务顺延过端口时最容易错）。
3. 访问 `http://localhost:<端口>/api/health`，应返回 `{"ok":true,"hasKey":true,...}`；`hasKey:false` 说明 Key 没配上。
4. `hasKey:true` 仍判分失败：看启动窗口日志里的上游错误；公司网络/代理需配 `DEEPSEEK_BASE_URL`，详见 `docs\部署说明.md` 第 4 节。

### Q4. AI 判分返回「模型返回的不是合法 JSON」或超时
- 偶发：直接重试一次。
- 持续：在上游不稳定或 Key 额度不足时出现；换 Key 或换端点后观察启动窗口日志。

### Q5. 换电脑 / 换浏览器后复习进度没了
- 进度存在浏览器 localStorage，按浏览器隔离，**不会自动跟账号走**。
- 同步方法：页面右上「导出进度」生成 JSON → 在新设备「导入」→ 导入前有预览，确认后再合并。详见 `docs\使用教程.md` 第 8 章。

### Q6. 手机访问电脑 IP 打不开
1. 确认手机和电脑连的是**同一个 WiFi**（不是 5G Guest 网络）。
2. 电脑防火墙放行 node.exe 的「专用网络」。
3. 关掉电脑上的 VPN / 网络隔离软件再试。

### Q7. 流程图不显示（只看到代码文本）
Mermaid 走公共 CDN，需要联网。离线环境下流程图会退化成代码块，不影响判分与复习功能。

### Q8. 想改判分严格程度
等级阈值在 `server.js`：`coverage <30 忘记了 / 30-60 模糊 / 60-85 熟练 / ≥85 完全掌握`；
「一句话结论」高权重在 `server.js` 的 gist 强制段（命中 ≥60、未命中 ≤55）。改数字保存后重启服务即可。

### Q9. 杀毒软件误报 node.exe / server.js
本包为零依赖 Node 脚本 + 官方 Node 运行时，无任何可疑行为。若被误报，加白名单后重试；不放心可改用系统 Node：删掉 `runtime\` 目录，装 Node 18+，脚本会自动回退到系统 node。

### Q10. 端口文件 `.server-port` 一直不消失
异常退出时可能残留，直接删掉即可；启动脚本每次启动前也会清理。

### Q11. 导入提取（PDF / Word / 图片 → 知识点 / 题库）相关
- 入口：总览页顶部「导入提取」按钮。支持 `.pdf` / `.docx` / `.jpg` / `.jpeg` / `.png` / `.gif`，单文件上限 50MB，可多选批量导入（也可以把文件拖进导入区）。
- 改扩展名的伪装文件、超限文件、旧版 `.doc`（OLE2）会被拒绝并给出原因；`.doc` 请先「另存为 .docx」。
- PDF 数字页直接取字；扫描页（该页文本 < 50 字符）才触发 OCR，单文件最多 OCR 30 页。
- 首次 OCR 会下载约 20MB 中文语言包，耐心等待；同一浏览器再次使用有缓存。潦草手写体识别率有限，生成结果请人工核对（低置信度条目会高亮提示）。
- 生成的知识点 / 题库可编辑、标「已确认」、按文件筛选，并导出 JSON / CSV / Excel 三种格式。
- Excel 导出下载下来是 CSV：jsdelivr CDN 不可达时自动回退，联网后重试即可，数据不丢。
- 提取结果存在浏览器 IndexedDB，不随账号同步；换设备请用结果区「导出 JSON」搬运。

### Q12. 判分失败：`Cannot convert argument to a ByteString…`
这条英文天书的含义是：**API Key 里混进了非英文字符**（最常见：直接改名 `deepseek.key.example` 时第一行还是中文注释，旧版本会把注释当成 Key）。v2.0.2 起不会出现了——解析时自动跳过 `#` 注释行，且 Key 含中文/全角字符会直接返回可读的中文报错。若你用旧版遇到：打开 `deepseek.key`，确保某一行只有 Key 本身（行首不要带 `#`，也不要写中文备注），或升级到 v2.0.2。

## 6. 功能模块说明

### 6.1 模块总览

| 模块 | 位置 | 是否依赖服务 |
|---|---|---|
| 题库浏览（296 题） | 总览页 / 分章页 | 否 |
| 分层笔记：一句话结论 + 折叠详情 + 表格/代码/Mermaid 流程图 | 题目卡片 | 否（流程图渲染需联网） |
| 全部展开/折叠 + 实时搜索高亮 | 顶部工具栏 | 否 |
| 分级复习（五级 + 篮子 + 复习模式） | 侧边栏 + 顶部「复习模式」 | 否 |
| AI 自测（默写复述 → DeepSeek 判分） | 卡片右上「AI 自测」 | **是** |
| 深测（AI 先出 3 道简答 → 综合判分） | 自测面板第二个 Tab | **是** |
| 进度导出 / 导入（多设备同步） | 顶部工具栏 | 否 |
| 文件导入与内容提取（PDF/docx/图片 → 知识点/题库） | 顶部「导入提取」 | 本地解析否，生成步骤**是** |
| 静态托管 + API 代理 | server.js | **是**（它本身就是服务） |

### 6.2 五级记忆等级与判分

| 等级 | 判定 | 排期策略 |
|---|---|---|
| 未记忆 unseen | 从未自测 | — |
| 忘记了 forgotten | DeepSeek 判 coverage < 30，或复述为空 | 当天重新到期 + **强制重学**（须回顾答案才能复测） |
| 模糊 fuzzy | coverage 30–59 | 1 → 3 → 7 天递增，封顶 7 天 |
| 熟练 skilled | coverage 60–84 | 毕业后走 7 / 15 / 30 / 60 天长线 |
| 完全掌握 mastered | coverage ≥ 85 | 毕业后走 30 / 60 / 120 天长线 |

**「一句话结论」高权重**：每张卡片顶部的一句话结论是最高权重要点（权重≈其余要点之和）——复述说对它，覆盖率至少 60（熟练）；没说或说反，覆盖率至多 55（摸不到熟练）。判分结果面板会显示「核心结论已命中 / 未命中」。

**附加规则**：表述正确率 accuracy < 40（有明显事实错误）时封顶只能判「模糊」。

**毕业门控**：连续 2 次自测达到熟练及以上才毕业离开待复习队列；毕业后到期 gate 归零，需重新证明。

### 6.3 服务端接口（排障用）

| 方法与路径 | 作用 |
|---|---|
| `GET /api/health` | 探活：返回 `{"ok":true,"hasKey":...}` |
| `POST /api/judge` | 判分：入参 `{question, reference, gist, answer}` 或 `{qa:[...], mode:"deep"}` |
| `POST /api/quiz` | 深测出题：入参 `{question, reference}`，返回 3 道简答 |
| `POST /api/kpoints` | 知识点抽取：入参 `{chunks:[{text,page}]}`（最多 30 块），返回最多 25 条 |
| `POST /api/qbank` | 题库生成：入参 `{chunks, points?}`，返回选择题 / 填空题 / 简答题 |
| `GET /review` | 302 跳转到总览页 |
| `GET /<文件>` | 静态托管本目录所有文件 |

### 6.4 数据与隐私

- 全部复习数据仅存于**当前浏览器**的 localStorage（key：`eb-review-system-v1`），不上传任何服务器。
- **导入的文件不会上传服务器**：PDF / Word / 图片全部在浏览器本地解析（pdf.js / mammoth / tesseract.js），发往服务端的只有提取出的文本块；提取结果存浏览器 IndexedDB（`eb-extract-v1`，四 store：files / blocks / points / questions）。
- AI 判分时，题目标题 + 答案要点 + 你的复述文本会发送到你所配置的上游端点（默认 DeepSeek 官方）。
- API Key 只存在于服务端（环境变量或 `deepseek.key`），**不会进入浏览器页面**，导出进度文件也不含 Key。
