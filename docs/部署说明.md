# 知识复习工作台 · 本地部署说明

适用版本：3.0.0；更新：2026-10-02。云端静态部署见[免费托管与云同步](免费托管与云同步.md)。

## 启动

Windows 便携包双击启动.cmd，或在项目目录执行：

```powershell
runtime\node.exe server.js 8000
```

Git 源码不含运行时；安装 Node 18+ 后使用 `node server.js 8000`。Linux/macOS 使用 `bash 启动.sh 8000`。启动脚本等待服务就绪后打开浏览器，端口占用最多顺延 10 次；以实际启动输出为准。停止服务按 Ctrl+C。

入口为 `http://localhost:8000/review`。默认仅监听 127.0.0.1；同一 WiFi 访问时，在 PowerShell 设置后启动：

```powershell
$env:REVIEW_HOST = '0.0.0.0'
runtime\node.exe server.js 8000
```

按需放行专用网络防火墙，手机访问电脑实际 IP 和端口。局域网不同来源的数据独立，不是共享数据库。普通局域网 HTTP 不满足 PWA 安全上下文要求；云端安装使用 HTTPS。

## 可选 AI 配置

复制 deepseek.key.example 为 deepseek.key，填入自己的 Key，或设置 DEEPSEEK_API_KEY。读取优先级为环境变量、密钥文件；文件忽略空行与注释。AI_MODEL 可覆盖模型，DEEPSEEK_BASE_URL 指定兼容 chat/completions 的端点。修改服务端参数后重启服务。

`/api/health` 的 hasKey 表示配置情况，不保证额度与上游实际可用。无密钥时本地学习可用，AI 入口禁用。密钥不要提交 Git、写入前端或上传静态托管。本地服务限制公共资源访问并拒绝跨来源 AI 请求，不适合直接暴露到公网；公网 AI 需要另行设计认证与额度管理。

## 更新与数据保留

1. 在原浏览器、原网址导出完整备份，原始资料另行保管。
2. 更新工程文件，保持原访问地址以继续读取原 localStorage/IndexedDB。
3. 修改内置题库或外壳后运行 `node scripts/build.cjs`；部署 PWA 时运行 `node scripts/build-cloud.cjs`。
4. 已安装 PWA 的用户通过“更新应用版本”启用新缓存。云端数据应用是另一入口；编辑/自测期间暂缓应用。
5. 换网址时通过完整备份迁移，不清空旧来源数据。回退程序版本前先备份，新版本数据格式不保证旧版完全支持。

## 开发验证

```powershell
runtime\node.exe --test tests\core.test.cjs tests\cloud.test.cjs tests\features.test.cjs
runtime\node.exe scripts\build-cloud.cjs
```

静态产物为 dist，上传其内容，不上传整个工程。未提供 Supabase 公开配置时是本地模式，不代表已上线同步。版本来自 VERSION 与 package.json，两者当前均为 3.0.0；数据 schema 的 version 与应用版本不同，不随发布号随意修改。

## 数据位置

题库、进度、模块配置在浏览器 localStorage，登录账号有独立命名空间；提取工作区在 IndexedDB（eb-extract-v1）。完整备份不包含提取工作区、原始文件、凭据。不要通过 localStorage.clear 或删除数据库作为普通升级步骤。

真实云端、手机安装和 AI 验收待服务配置后完成，见[测试用例](测试用例.md)。
